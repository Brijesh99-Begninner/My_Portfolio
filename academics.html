CASE STUDY #1

Amazon Homepage & Grid Clone

HTML5 CSS Grid & Flexbox Responsive Cards

A detailed frontend reconstruction of the Amazon homepage dashboard. The objective of this project was to master complex, multi-level grid card containers that resize dynamically, and replicate Amazon's dense navigation header and layout system.

Run Live Program ↗ View Source Code

Replicating Amazon's overlapping hero banner and the dense, multi-column category grid was challenging. The layout needed to maintain uniform vertical alignment despite product descriptions and image dimensions changing across card categories.

Leveraged nested CSS Grids: a parent 4-column container with explicit rows, containing 2x2 grid sub-cards. The search bar utilized Flexbox with absolute-sized buttons and custom borders to guarantee uniform heights.

Gained absolute control over container alignments using `align-items: stretch` and aspect-ratio styling, minimizing layout shifts on smaller viewports. Refined custom scroll behaviors and hover borders.

CASE STUDY #2

Netflix Interface & Sliding Rows

HTML5 CSS Flexbox Rows Gradients & Blurs

A replica of the Netflix browse interface featuring an immersive hero banner with dynamic title overlays, a custom gradient overlay that blends into dark content, and horizontally scrollable movie categories.

Run Live Program ↗ View Source Code

Replicating Netflix's signature "card expansion" hover effect, where hovering a movie tile zooms and reveals metadata without shifting the surrounding layout, was highly complex.

Designed rows using Flexbox with overflow-x scroll mechanisms. Employed CSS 3D transforms (`transform: scale(1.15)`) coupled with `z-index` elevations to keep zoomed cards elevated.

Gained deep knowledge of the stacking context in CSS, transition speeds, and using radial/linear dark gradients to guide user attention.
